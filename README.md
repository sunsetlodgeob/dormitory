# 夕照寮OB会サイト

横浜市立大学の男子寮「夕照寮」（1970–2010）の OB 会のサイトです。寮はなくなりましたが、その思い出をゲームと資料で残して、みんなで共有します。

- 公開先：https://sunsetlodgeob.github.io/dormitory/ （GitHub Pages）
- ふつうの HTML・CSS・JavaScript だけで書いてあります。ビルドもインストールもいりません。ファイルを置けば動きます。
- 横浜市立大学の公式サイトではありません。夕照寮OB会の有志が作っています。
- このサイトに出てくる事件やゲームの題材は誇張であり、すべてフィクションです（どのページの下にも出ています）。

### 名前とデータの扱い

- 名簿・部屋割り・年表の中身は、OB 会のスプレッドシートにあります。ページを開いたときに読みこみます。このリポジトリには実名を入れません。
- 設定（`js/site/config.js`）が空のときは、`js/site/sample.js` の架空の名前で動きます。そのときは、ページに「サンプル」と出ます。
- ゲームの登場人物は「先輩A」「同期B」「一年C」のように呼び、名前を出しません。
- 寮の写真は人物が写っているので、リポジトリに入れません（`.gitignore` 済み）。

## 手元で動かす

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。Google のログイン（年表）を手元で試すときは、`docs/site/SETUP.md` の手順 8 で `http://localhost:8000` を登録しておきます。

## 操作

- パソコン：矢印キーで動かす。Z か Enter で決定（A ボタン）、X で もどる（B ボタン）。M で音のオン・オフ（ゲーム）。
- スマホ：画面の下の十字キーと A・B ボタン。画面をタップしても選べます。
- 音は、最初にボタンを押したあとに鳴ります。どのページも「音」のボタンで止められます。
- ゲームの進み具合や音の設定は、そのブラウザの中にだけ保存します（`docs/site/ARCH.md` の 5）。

## 確認（テスト）

ヘッドレスの Chromium（Playwright）で、ページを実際に動かして確かめます。

```sh
sh tests/run-all.sh                    # ぜんぶ（30 分ほど）。失敗があると終了コードが 0 以外
node tests/e2e/site.test.js            # サイト全体を 1 回ずつ回る（ページのつながり・注記・スマホの幅）
node tests/e2e/home.test.js            # ページごと（home・game・story・heya・meibo・nenpyo・d1・games-*）
node tests/gas/run.js                  # Apps Script（gas/Code.gs）。Google には出ない
PORT=8821 node tests/e2e/home.test.js  # ポートを変える
```

Playwright は `/opt/node22/lib/node_modules/playwright` か、ふつうの `require('playwright')` で読みこみます。ポートの割り当てなどは `docs/site/ARCH.md` の 6 にあります。

## Google 側の設定（幹事向け）

トップページの投稿フォーム → Gemini で整理 → スプレッドシート（そのまま掲載）→ サイト、の流れは Google Apps Script で動きます。設定の手順は [`docs/site/SETUP.md`](docs/site/SETUP.md)、コードは [`gas/`](gas/) です。設定が終わったら、`js/site/config.js` に URL などを書きこみます。

## 寮さんぽ（`sanpo/`）

新入生になって寮に入り、先輩たち 10 人にあいさつ回りをすると、屋上で夕焼けのエンディングが見られます。

- パソコン：矢印キーか WASD で移動、Z / Enter / Space で話す・調べる、X か Shift を押しながら走る。
- スマホ：画面下の十字キーと A・B ボタン。行きたい場所や人をタップすると、そこまで自動で歩きます。
- 進み具合はブラウザに自動保存され、タイトル画面の「つづきから」で再開できます。
- 部屋割りのページの「この年度の寮を歩く」から来ると（`sanpo/?year=2005` など）、部屋のドアを調べたときに、その年度の住人の名前が出ます。
- 廊下の東のつきあたりは非常口。1階はここからも外に出られ、出るとすぐ寮の前です（2階・3階は調べるだけ）。

### 再現のもとにした資料

#### 提供資料（間取り図と記憶メモ）

間取りと部屋のようすは、提供された間取り図と記憶メモ（`docs/dorm/`）にもとづいています。

- 3階建て＋屋上。居室は35室（1階に101、2階・3階に17室ずつ）で、間取りはすべて同じ。
- 1階の西のはしに厨房と食堂（建物の奥行きいっぱい）。玄関を入るとまっすぐ先が階段で、見えるドアは管理人室。左へ行くと食堂、右へ行くと勉強部屋や風呂場。
- 玄関を入って右手に郵便受け、その奥に下駄箱。左手（食堂の入口の手前）にも下駄箱。食事表は食堂の中の壁で、入口の扉と本棚のあいだのすき間にある。
- 各階に、洗面所とキッチンが一緒になった部屋（2口コンロ・掃除用の流し）、トイレ、物置。1階にはボイラー室と灯油庫も。
- 居室はどれも同じ間取り（持ち主の図）。窓（ベランダ側）はまん中で、窓側の左右のすみに机が1つずつ。左の壁ぞいに2段ベッド（はしごは少しだけ斜め）。その先（ドアの側）に、床から天井までの作りつけの収納（上下2段）があり、ベッドはほとんどそれにくっついている。右の半分は床で、ドアは窓と反対の壁の右寄り。本棚（中身はほとんどマンガ）は、ベッドの下の段の壁ぎわに置いた。机のあった場所に冷蔵庫を置いた部屋、床がボロボロの部屋、段ボールで補修した部屋もある。ドアは開けっぱなしのことが多い。
- 浴槽は浴室の右下（間取り図で見て）。
- 食堂：自販機が2台（道路側のコカ・コーラと、管理人室へのドアの近くの当たり付きのダイドー）。コカ・コーラの横に冷蔵庫が2台（名前を書かずに入れた物は、誰が食べてもいい）。道路側の窓ぎわの正方形のテーブルで麻雀。卒業生が置いていったマンガの本棚、全日本コール選手権の優勝トロフィー、部屋割りの表。厨房はふだんカギがかかっていて、寮生は入れない。
- 管理人室：電話（夕方の電話当番があったが、ほとんど鳴らない）と、館内放送のマイクがついた小窓。
- 屋上では BBQ をしたり、布団を干したりしていた。
- 玄関の外から見ると、食堂の道路側の窓が少し張り出していて、バルコニーのように見える。
- 廊下の東のつきあたりは非常口のドア。外には非常はしごがあり、2階・3階からは出入りできないが、1階はふつうに出入りできた。
- 両はしのトタン屋根の小屋が置き場の屋根。寮に向かって左がバイク置き場、右が自転車置き場。
- 道路側から見た外観の写真（リポジトリには入れていません）：2階・3階の道路側に、茶色い手すりと部屋ごとの白い仕切りのベランダ（洗濯物）。ベランダはすべての居室にある（東のはしの物置の前にはない）。屋上のふちは白く張り出す。玄関のまわりに平らなひさし、勉強部屋の前に白い柱の低い柵、東のはしの2階にエアコンの室外機、その上の3階（物置）に窓、東の面に非常口の踊り場と赤い非常はしご。
- 自転車は20台以上あった。白いミニバンはフェンスの側に停まっていた。

### 推測で補ったところ（要確認）

- 方位：間取り図の下を道路側（南）、上を川側（北）とした（玄関が道路側にあるため）
- 窓とドアの位置（居室の窓・机・ベッド・収納・ドアと、浴槽の位置はうかがった内容どおり）
- 居室のイス・本棚の場所と、部屋ごとの飾りを置いた場所（右の半分のあいている所など）。本棚は、ベッドの下の段の壁ぎわに置いた
- 居室の収納の戸の向き（絵では、見下ろしの決まりで手前の面に描いた）と、上の段・下の段に入っている物
- 脱衣所が西・浴室が東という並びと、ボイラー室の場所（資料でも仮置き）
- 床・壁・ドアの色：食堂のオレンジの床と黄色い壁、廊下の青い床、居室の寄木の床、水色のドア（写真から読み取った印象で、未確認）
- 厨房・宿直室・勉強部屋の中の家具の並び
- 部屋ごとの飾りつけ（どの部屋だったかは資料でもわからないので、部屋番号との組み合わせは架空）
- 外観：外壁の色、玄関の看板の位置、停まっている車の車種（色と位置は航空写真の印象から）
- 外観の写真から読んだところ：ひさしの左右のはば、雨どい・メーターの位置、非常口のドアの形と踊り場の大きさ、3階の物置の窓の大きさ
- 1階の非常口を出たところは、出てすぐ寮の前（持ち主の話）。外の地図では、灯油庫を 1 列右にずらして、非常口の前をあけた
- 自転車とバイクの台数・車種（自転車は 27 台、バイクは原付のスクーターとカブにした）
- 下駄箱と食事表の大きさ（場所はうかがった内容どおり）
- 登場人物とセリフはすべて架空です

### 間取りの直し方

間取りは `js/world.js` に 1 文字 = 1 マスのテキストで書いてあります。たとえば 2 階の上の 2 行はこうです。

```
'##ww##Aww##Aww###ww###ww###ww###ww##Aww###ww###w########',
'#d,,d#d,,d#dG,d#d,,,#d,,F#VVUU#daad#d**d#s-sL#CCuu#kkXX#',
...
```

`#` が壁、`w` が窓、`+` がドア、`/` が開けっぱなしのドア、`d` が机、`b` が2段ベッド（居室は 2×3 マス）、`p` が収納……のように、記号の一覧はファイルの先頭にあります。文字を書きかえて保存し、ブラウザを再読み込みすると反映されます。外から見た窓の位置は、各階のいちばん下の行（道路側の壁）から自動で決まります。
