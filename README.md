# 夕照寮 ドット絵さんぽ

横浜市立大学の男子寮「夕照寮」（1970–2010）をドット絵で再現し、建物の中を歩きまわれるようにした小さなブラウザゲームです（試作版）。

新入生になって寮に入り、先輩たち 10 人にあいさつ回りをすると、屋上で夕焼けのエンディングが見られます。

個人による非公式の再現で、横浜市立大学とは関係ありません。

## 遊び方

- `index.html` をブラウザで開くだけで動きます（インストール不要・画像ファイルなし）。
- パソコン：矢印キーか WASD で移動、Z / Enter / Space で話す・調べる、X か Shift を押しながら走る。
- スマホ：画面下の十字キーと A・B ボタン。行きたい場所や人をタップすると、そこまで自動で歩きます。
- 進み具合はブラウザに自動保存され、タイトル画面の「つづきから」で再開できます。

## 想像で補ったところ（要確認）

- 間取り：中廊下の両側に部屋、西端に階段、東端にトイレ・洗面所という形と、各階の部屋数
- 2人部屋という設定、ベッド・机・収納・フローリングの床
- 1階の食堂・厨房・浴場・談話室・管理人室・玄関の位置と、各階の補食室
- 屋上に出られること、外壁や窓の形、玄関の看板、前庭の桜と自転車置き場
- 登場人物とセリフはすべて架空です

## 間取りの直し方

間取りは `js/world.js` に 1 文字 = 1 マスのテキストで書いてあります。たとえば 2 階はこうです。

```
'##ww###ww###ww###ww###ww###ww###ww###w#w##',
'#VVUU#bddb#bddb#bddb#,,,,#bddb#bddb#CCCuu#',
...
```

`#` が壁、`w` が窓、`+` がドア、`b` がベッド、`d` が机……のように、記号の一覧はファイルの先頭にあります。文字を書きかえて保存し、ブラウザを再読み込みすると反映されます。外から見た窓の位置は、各階のいちばん下の行（南側の壁）から自動で決まります。

## 実物に近づけるために知りたいこと

- 部屋は個室か相部屋か。床は畳かフローリングか
- 1 階の間取り（玄関・管理人室・食堂・風呂・階段の位置）と、各階の部屋数・部屋番号の付け方
- 外壁の色、ベランダの有無、玄関の向き、屋上に出られたか
- 「夕照寮」の読み方
- 写真や見取り図があれば、それをもとに描き直せます
