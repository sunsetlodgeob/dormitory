# gas/ ― OB会サイトの Google 側（Apps Script）

鍵付きのスプレッドシート 1 つに付けて使うスクリプトです。設定の手順は [docs/site/SETUP.md](../docs/site/SETUP.md) を見てください。

```
寮生 ─ Google フォーム ─▶ 回答シート ─ onFormSubmit ─ Gemini で整理 ─▶ 年表・名簿・部屋割り シート（掲載はチェックなし）
                                                                         │ 幹事が確認して「掲載」にチェック
サイト ◀─ doGet ?type=public（名簿・部屋割り。誰でも）────────────────────┤
サイト ◀─ doPost {type:'timeline', idToken}（年表。見る権限のある人だけ）──┘
```

| ファイル | 中身 |
| --- | --- |
| `Code.gs` | スクリプト本体。Apps Script の「コード.gs」に貼る |
| `appsscript.json` | 設定（タイムゾーン、ウェブアプリの公開のしかた、使う権限） |

## 関数

| 関数 | すること |
| --- | --- |
| `setup()` | 最初に 1 回実行。シート（年表・名簿・部屋割り・メンバー）、フォーム 2 つ、回答のトリガーを作る。何度実行しても増えない。スプレッドシートのオーナー（OB会のアカウント）以外が実行すると止まる |
| `showFormUrls()` | フォームの URL をもう一度ログに出す |
| `onFormSubmit(e)` | フォームの回答を Gemini で整理して、シートに 1 行足す。Gemini が使えないときは原文のまま足し、メモに「Gemini失敗：手で整理してください」 |
| `doGet(e)` | `?type=public` で、掲載にチェックした名簿・部屋割りを返す（5 分キャッシュ） |
| `doPost(e)` | Google の ID トークンを確かめ、見る権限のある人に、掲載にチェックした年表を返す |
| `onEdit(e)` | シートを手で直したら、キャッシュを消す（すぐサイトに出る） |

返すデータの形は [docs/site/ARCH.md](../docs/site/ARCH.md) の「データの形」と同じです。

## 守っていること

- サイトに返すのは「掲載」にチェックした行の、決まった項目だけ。メモ・元の回答・メールアドレスは返さない。
- 名簿に「いいえ」と答えた人の行は、メモに「名簿掲載NG」と書き、チェックしてもサイトに出さない。
- Gemini に送るのは、事件の「いつごろ・見出し・何があった」と、名簿の「入学年度・卒業年度・部屋」だけ。お名前・関わった人・投稿者は送らない。
- 回答の文字が `=` などで始まっても、スプレッドシートの式として動かないようにする。「4/1」「1234」なども、日付や数に化けない。

## スクリプト プロパティ

| 名前 | 中身 |
| --- | --- |
| `GEMINI_API_KEY` | Google AI Studio で作った API キー |
| `GEMINI_MODEL` | 任意。使うモデル（なければ `gemini-flash-latest`＝いちばん新しい Flash。入れたモデルが 404 なら、こちらでやりなおす） |
| `CLIENT_ID` | 年表のログイン用の OAuth クライアント ID（`js/site/config.js` の `GOOGLE_CLIENT_ID` と同じ） |

ほかの値（フォームの ID など）は `setup()` が入れます。

## 確認

```
node tests/gas/run.js
```

Apps Script のサービスをまねたもの（`tests/gas/gasmock.js`）の上で動かします。Google にはつながりません。
