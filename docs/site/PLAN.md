# 夕照寮OB会サイト 企画書

廃寮となった横浜市立大学の男子寮「夕照寮」の OB 会サイト。寮の思い出を、ゲームと資料で残して共有する。

- 公開目標：**11/21**（寮生大会 11/28 の 1 週間前。大会当日の待ち時間にも流せるように）
- 置き場所：GitHub リポジトリ `sunsetlodgeob/dormitory` → GitHub Pages
- 元の案：OB 会サイトのコンテンツ案（スプレッドシート）

## 1. サイトの構成

```
ホーム（モード選択）
├─ ゲーム ……… 男魂くんの1年（ミニゲーム 10 本）
└─ コンテンツ
   ├─ 年表 ……… 事件簿を年表に（Google ログインした人だけ表示）
   ├─ 部屋割り … 年度を選んで、ドット絵の寮を訪問／一覧表
   ├─ 名簿 ……… 入学年度別（年度と名前だけ）
   ├─ 写真館 …… Google のアルバムへのリンク（ログインした人だけ）
   └─ 寮さんぽ … 寮の建物を歩ける再現（今ある「夕照寮 ドット絵さんぽ」）
```

すべてのページに「このサイトに出てくる事件やゲームの題材は誇張であり、すべてフィクションです」と書く。

## 2. 公開の範囲

| 内容 | 見られる人 | 置き場所 |
| --- | --- | --- |
| ホーム・ゲーム・寮さんぽ | 誰でも | GitHub Pages |
| 名簿・部屋割り（年度と名前） | 誰でも | 公開用スプレッドシート → サイトが読む |
| 年表（事件簿、ぼかさない） | 見る権限を与えた人 | 鍵付きスプレッドシート → Google ログインでサイトに表示 |
| 写真館 | 見る権限を与えた人 | Google のアルバム（サイトにはリンクだけ） |

- ゲームの登場人物は「先輩A」「同期B」のように、名前を出さない。
- 実名や個人の連絡先は、リポジトリに入れない（名簿の元データはスプレッドシートに置き、サイトは表示するときに読む）。
- 寮の写真は参考にするだけで、リポジトリには入れない（`.gitignore` 済み）。

## 3. 各ページ

### ホーム
- ファミコンウォーズ「風」の画面（絵と音楽はオリジナル。本物の素材は使わない）。
- 寮のマップの上でカーソルを動かして「ゲーム」「コンテンツ」を選ぶ。BGM はピコピコ音。

### ゲーム「男魂くんの1年」
20xx年に入寮した新入生・男魂くんが、1年間の行事をこなす。登場する寮生は過去の寮生全員（ただし学年は不明、名前は出さない）。

- 全部クリア → 寮になじんで**留年確定**（ハッピーエンド）
- 途中で失敗 → 途中退寮。中途半端に寮の影響を受けたので友達もできず、**留年確定**
- キャラ：男魂くんだけ専用の絵。ほかは共通の絵を仮に入れ、あとで描き分ける。
- ミニゲームはレトロなドット絵から外れてもよい。

| 月 | 行事 | ミニゲーム |
| --- | --- | --- |
| 4月 | 新歓 | 自分に振られたら飲む、限界が来たら吐く、を間違えずに繰り返せ |
| 4月 | 新歓 | ニセ一年が1人まぎれている。一年が気を利かせてくる中、怪しいやつの申し出だけ断れ（断りすぎると友達ができない） |
| 6月 | ― | 牛丼を食べていたら財布がない。店員の目を盗んで店を出ろ |
| 7月 | ― | 泥酔して消えた同期Bを探せ。上り・下りどちらの電車にいるかはランダム。落とした服やカバンが手がかり |
| 9月 | ― | 全裸でコンビニに行った帰り、投げつけられるカラーボールを全部よけて、警察から逃げきれ |
| 10月 | ― | 寮生全員がゾンビになった。全員なぐって正気に戻せ |
| 11月 | 学祭 | 女子100人の勧誘を成功させろ（成否はランダム） |
| 2月 | 節分 | 投げつけられる物に耐えてピラミッドを完成させろ。警察が来たら中に逃げろ |
| 3月 | 追いコン | 後ろから投げられるうんこをよけろ |
| 3月 | 追いコン | 全裸で切符を、誰にも見られずに買いに行け |

（「時期なし」の4本は、仮に6〜10月に置いた）

### 年表
- 事件簿（古文書）を年表にする。年度ごとに並べ、ドット絵ふうの見た目で読む。
- データは鍵付きのスプレッドシート。サイト上の「Google でログイン」を押し、そのシートを見る権限がある人にだけ表示する。
- 寮生がフォームで事件を投稿できる（下の「データの流れ」）。

### 部屋割り
- 年度を選ぶと、ドット絵の寮（2・3階の 35 室）で各部屋を訪問できる。ワンタッチで一覧表にも切りかえられる。
- わからない所は空欄のままにし、あとから情報をもらって埋める。
- 部屋をノックしたときの反応は、集め方が決まってから（後回し）。

### 名簿
- 入学年度別に名前を並べる。わかる人は卒業年度も出す。
- 「載せたくない人は連絡を」と書いておく。

### 写真館
- Google のアルバム（ログインした人だけが見られるもの）へのリンクを置く。
- 写真の集め方・月ごとの仕分け・重複の削除は、アルバム側で進める（このサイトの外）。

## 4. データの流れ

```
寮生 ─ Google フォーム ─▶ 回答シート
                           │ GAS（Google Apps Script）が新しい回答を見つけると
                           ▼ Gemini に渡して、年度・見出し・本文を整理
                        整理シート（幹事が「掲載OK」にしたものだけ）
                           │
          ┌────────────────┴────────────────┐
     年表（鍵付き）                    名簿・部屋割り（公開用）
   Google ログインで読む            公開シートをサイトが読む
```

- Gemini の無料枠に通した文章は、Google が改善に使うことがある。実名入りの事件簿を通すなら、有料枠にするか、名前を伏せてから通す。
- フォームとスプレッドシートと GAS は OB 会の Google アカウントで作る。GAS のコードと設定手順はこちらで用意する。
