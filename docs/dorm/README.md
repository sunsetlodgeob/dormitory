# 男子寮 再現資料（入口）

男子寮（横浜市金沢区六浦東1-49-6）の内部を再現するための資料一式です。

## 最初に読む順

1. `dorm_reference.md` : 間取り、場所ごとの特徴、写真の索引（文字版）。まずこれを読む。
2. `floorplan.png` : 間取り図（1階〜3階）。画像として見る。
3. `photos/` : 寮の写真97枚。`dorm_reference.md` の索引から番号で探す。

## フォルダの中身

```
dorm/
├─ README.md            この入口
├─ dorm_reference.md    文字版の資料（間取り・特徴・写真の索引）
├─ floorplan.png        間取り図
├─ photos_index.csv     写真の索引（表計算で開ける形）
├─ photos/              写真（長辺640px）
│   ├─ exterior/        外観・屋上
│   ├─ entrance/        玄関・廊下・階段
│   ├─ dining/          食堂・厨房
│   ├─ staff_study/     管理人室・勉強部屋
│   ├─ rooms/           居室
│   └─ water/           水回り
└─ source/dorm_tags.csv 持ち主が仕分けた全648枚の記録（再仕分け用。普段は読まなくてよい）
```

## 使うときの注意

- メモ（場所・メモ欄、特徴の文）は持ち主の記憶で、基本的に正しい。「AI所見」は未確認なので、メモを優先する。
- 写真は縮小版。元の高画質写真は持ち主のPCにある。必要なら持ち主に頼む。
- 人物が写っている写真が多い。外部に公開・共有しないこと。
- 資料にないこと（窓・ドアの位置、方位、寸法など）は、推測で決めず、持ち主に確認する。
- 何を作るか（形式）は、持ち主の指示に従う。部屋ごとの違いはドット絵のような簡単な表現でもよい、という希望がある。
